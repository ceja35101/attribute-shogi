# Elemental Shogi Free Beta Test

Play: https://ceja35101.github.io/attribute-shogi/

Select **English** from the gear menu. The tutorial contains four interactive practice battles.

## Test Goal

We want to learn whether new players can understand the element cycle, predict battle results, finish a game, and identify confusing controls.

## Suggested Session

Play for 20–40 minutes or complete one game. You do not need to be an experienced Shogi player.

Please check:

1. Can you understand Fire → Wind → Water → Fire?
2. Can you distinguish pieces, elements, and legal destinations?
3. Can you predict advantage, counterattack, clash, and reinforcement results?
4. Can you use promotion, pieces in hand, check responses, undo, and replay?
5. Did the game finish without becoming stuck?
6. Would you play again?

Use **Copy Feedback Template** in the gear menu. If you have a GitHub account, use **Send Bug Report / Feedback**.

The game does not automatically transmit personal data or game records.

## Known Limitations

- CPU matches and two-player matches on the same device
- No online multiplayer
- Android Chrome has not been tested on physical hardware
- English localization is in beta
- Rules and save formats may change
