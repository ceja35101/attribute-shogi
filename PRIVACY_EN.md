# Privacy

Elemental Shogi Ver0.1 does not send personal information or game records to a server.

The following data is stored only in your browser:

- CPU difficulty
- Display language
- Sound and volume settings
- Tutorial completion state
- Board position, pieces in hand, elements, promotions, King durability, and clash state
- Turn, move log, complete game record, and replay snapshots
- A backup of saved data that could not be restored

You can remove this data by clearing the site's browser data. The in-game Reset button removes the current saved match. There are no analytics, advertisements, accounts, or automatic telemetry.

The feedback-template button only copies text to the clipboard. Data leaves the game only when you deliberately open the external GitHub feedback page and submit it yourself.
